# Aula 01 — Entrada e saída no terminal

- `input()` exibe uma pergunta e devolve como texto o que você digitou antes de pressionar Enter.
- Uma **variável** dá um nome a um valor. Na linha `nome = input("Qual é o seu nome? ")`, a variável `nome` guarda a resposta.
- `print()` mostra uma mensagem no terminal. Em `f"Olá, {nome}!"`, o Python coloca o valor de `nome` no lugar de `{nome}`.
- Uma linha que começa com `#` é um comentário. Use comentários para explicar o que o código faz.

Abra o [exercício de saudação](../exercicios/01_saudacao.py) e tente prever a mensagem antes de executar o programa. [Tutorial oficial do Python sobre entrada e saída](https://docs.python.org/pt-br/3/tutorial/inputoutput.html)
