# Projetos práticos

## Lista de tarefas em um arquivo

Peça uma tarefa no terminal e salve o texto em um arquivo `tarefas.txt`. Depois, faça o programa mostrar as tarefas já salvas. Esse projeto pratica leitura e gravação de arquivos.

## Resumo de anotações com IA

Depois de praticar com arquivos, leia um arquivo de anotações de exemplo, envie o texto a uma API de IA com um pedido de resumo em três tópicos e salve a resposta em `resumo.txt`. [Guia de início rápido da API da OpenAI](https://developers.openai.com/api/docs/quickstart)
